# Thiết kế JMeter
## Thiết kế CSV — làm riêng trước JMX
- Dựa trên workflow đã duyệt, xác định trường đầu vào, kiểu dữ liệu và ràng buộc; phân biệt trường CSV với JWT/ID do runtime trả về.
- Đề xuất header, số dòng và lý do, UTF-8, delimiter, quoted data, sharing mode, recycle/EOF và cách tạo tên duy nhất. Không giả định số dòng phải bằng số VU khi recycle base name an toàn.
- Với workflow tạo/xóa record, CSV có thể chứa tên cơ sở không rỗng; tên runtime gồm run/engine/thread/iteration và UUID. Điều chỉnh schema theo hợp đồng đã duyệt. Không hardcode ID, token hoặc password. Credential cấu hình local riêng được ignore. Không tạo record thật trong bước CSV.
- Khi được yêu cầu tạo CSV, kiểm tra parse, header, số dòng, giá trị trống, trùng base name, encoding và secrets; ghi đường dẫn, số dòng thực, hash và cách JMeter đọc header (không đọc header thành data). Ghi cấu trúc, lý do và kết quả kiểm tra trong báo cáo CSV. Không tạo JMX, chạy smoke hoặc tải nếu chỉ yêu cầu CSV. Chờ review trước bước Load.
## Tham số
Load: tải ổn định đại diện mục tiêu; ramp-up từ từ. Stress: các bậc tăng tải, có thời gian giữ mỗi bậc, tiêu chí dừng và quan sát recovery. Spike: baseline → tăng đột ngột → cao điểm → giảm → recovery; nếu Standard Thread Group không đủ, thiết kế nhiều nhóm đồng bộ thời gian và giải thích. Endurance: tải ổn định đã được pilot xác minh, HW05 khoảng 10–15 phút; không mặc định tìm được giới hạn tuyệt đối từ một lần chạy. Chốt VU, ramp, hold, duration, loop, think time, timeout, dừng an toàn và căn cứ phần cứng. Closed workload: RPS là kết quả đo, không bằng VU. Think time đặt đúng scope; ghi rõ timer có nằm trong transaction timing không.
## Cấu hình
HTTP Request Defaults host/port/protocol, timeouts; Header Manager Content-Type và Bearer đúng scope. CSV UTF-8, header, quoted data, sharing/EOF; không chứa secret. Nếu recycle base name phải thêm run/engine/thread/iteration/UUID. Credential lấy từ file local được ignore hoặc env qua script, không đưa vào CLI/log. Serialize JSON đúng kiểu. JSON Extractor dùng default sentinel và kiểm tra extraction. JSR223 dùng vars.get/put, không nhúng secret vào source/log. Reset biến từng iteration. Guard dependent requests bằng If Controller hoặc cơ chế tương đương; kiểm tra thực tế execution order và assertion failure policy. Không bỏ cleanup khi stop-thread.
## Report
HW05: cùng workflow cả 3 plan, CSV, tên MSSV_Load|Stress|Spike_YYYYMMDD.jmx theo ngày thực tạo, ba view khác nhau (ví dụ Load Summary, Stress Aggregate, Spike View Results Tree dùng để debug). Tắt listener nặng khi chạy tải và mở log tương ứng offline; ghi lại cách dùng. Không lưu response/sampler data/headers chứa secret. Nếu dùng Transaction Controller, chọn rõ có parent sample hay không; ưu tiên HTTP-only JTL để tránh đếm trùng. Đừng thay đổi mix sampler giữa các scenario mà không giải thích. Ghi cấu hình JMeter, test plan hash, CSV hash, runtime properties. Kiểm tra XML/hashTree và dry run được người dùng cho phép trước tải thực.
